# 內灣線轉乘攻略

以內灣線為起點或終點，查詢全台台鐵、高鐵與機場捷運轉乘行程。

🔗 https://neiwan-line.im1010ioio.dev/

支援跨日、轉乘時間與多種篩選條件，班表資料定期更新，行程計算在瀏覽器端完成。

## 主要功能

* 內灣線往返全台台鐵、高鐵與機場捷運
* 台鐵、高鐵與機捷轉乘行程計算
* 台鐵目的地可選擇包含高鐵轉乘，並保留純台鐵行程
* 支援跨日與同車續搭
* 六家／高鐵新竹步行轉乘
* 自訂各運具轉乘時間
* 台鐵對號列車與直達車篩選
* 提供未來班表查詢
* 顯示今日班次與出發狀態
* 使用者偏好保存在瀏覽器本機

內灣線列車、車站、景點、故事及美食內容目前保留入口，內容待後續補充。

## 台鐵與高鐵混搭

選擇接駁範圍外的台鐵車站時，可勾選「包含高鐵轉乘」，比較純台鐵與經六家／高鐵新竹的混搭行程。此選項預設關閉，去回程皆適用。

目的地已有在地高鐵接點時，使用該接點銜接台鐵。例如前往台南，搭高鐵到台南後經沙崙轉台鐵，不提供在台中下高鐵再接長途台鐵到台南的組合。勾選「主要幹線僅搭對號列車」時，仍保留必要的區間車接駁。

自動產生的行程須符合設定的轉乘時間；自行切換「可搭乘車次」可超出該範圍，網站會顯示提醒。可選車次不代表尚有座位或可購票。

支援的轉乘站與限制請見[台鐵與高鐵混搭說明](docs/high-speed-transfers.md)。

## 班表資料

班表資料主要來自：

* [臺鐵官方開放資料](https://ods.railway.gov.tw/)
* [TDX 運輸資料流通服務](https://tdx.transportdata.tw/)
* [桃園捷運](https://www.tymetro.com.tw/)
* [政府行政機關辦公日曆表](https://data.gov.tw/dataset/14718)

本站班表並非即時誤點、訂位或餘票資料，實際搭乘仍應以各運輸業者公告為準。

## 隱私

網站只有在使用者同意後才會啟用分析功能。

分析資料不包含起訖站、查詢日期、出發時間或查詢出的行程內容。

拒絕分析不影響網站主要功能。

### 各運具班表更新規則

- 台鐵：預設使用官方開放資料，每日重抓查詢範圍及跨日銜接日，不耗 TDX 額度。
- 高鐵：補齊新增、缺漏與失敗日期；另外重抓今天、明天、後天，以及一個最久未更新的較遠已取得日期。每個日期在一次執行中只抓一次，較遠日期只從官方已發布且未標記失敗的快取中挑選。
- 機捷：每日三次資料請求更新共用時刻、停靠模式與旅行時間，依星期及假日套用。
- 機捷改班：資料錯誤會阻擋發布；正常增減班、首末班與停站異動自動採用並保留差異報告；需舊結構修正且服務不同時才要求核實。依生效日切換已核實班表，未知效期且超過七天未更新時停止提供機捷行程。更新報告與原始資料保留在 Actions 附件，詳見 [機捷更新與改班核實](docs/metro-updates.md)。
- 保留既有強制全量更新功能；更新失敗保留原取得時間及資料並標記異常。日期數不等於 TDX 請求次數，還需計入分頁與供應日期清單。
