# 內灣線轉乘攻略

以內灣線為起點或終點，查詢全台台鐵、高鐵與機場捷運轉乘行程。

🔗 https://neiwan-line.im1010ioio.dev/

支援跨日、轉乘時間與多種篩選條件，班表資料定期更新，行程計算在瀏覽器端完成。

## 主要功能

* 內灣線往返全台台鐵、高鐵與機場捷運
* 台鐵、高鐵與機捷轉乘行程計算
* 支援跨日與同車續搭
* 六家／高鐵新竹步行轉乘
* 自訂各運具轉乘時間
* 台鐵對號列車與直達車篩選
* 提供未來班表查詢
* 顯示今日班次與出發狀態
* 使用者偏好保存在瀏覽器本機

內灣線列車、車站、景點、故事及美食內容目前保留入口，內容待後續補充。

## 本機開發

需要 Node.js 22.12 以上及 npm。

```sh
npm ci
npm run dev
```

正式建置：

```sh
npm run build
```

## 班表資料

班表資料主要來自：

* [臺鐵官方開放資料](https://ods.railway.gov.tw/)
* [TDX 運輸資料流通服務](https://tdx.transportdata.tw/)
* [桃園捷運](https://www.tymetro.com.tw/)
* [政府行政機關辦公日曆表](https://data.gov.tw/dataset/14718)

本站班表並非即時誤點、訂位或餘票資料，實際搭乘仍應以各運輸業者公告為準。

## 隱私

網站只有在使用者同意後才會啟用分析功能。

分析資料不包含起訖站、查詢日期、出發時間或查詢出的行程內容。

拒絕分析不影響網站主要功能。
