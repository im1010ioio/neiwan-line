# 選站主要站標示

核對日期：2026-09-22。特等站與一等站共 32 站，以加粗、主色站名顯示，不使用標籤；不影響排序、選站、停用規則與行程計算。高鐵不套用台鐵分級。

名單保存在 src/major-stations.ts，使用站點 ID，獨立於自動更新的站點資料；不額外呼叫 TDX。車站等級調整時須依官方資料更新此名單。

來源：

- [台鐵拍攝場地設備出借費率附件](https://www.railway.gov.tw/tra-tip-web/tip/file/5b974675-4c06-4de7-8859-d5f1633e162a)：B 類列出特等、一等站，但排除已歸入 A 類的古蹟與支線場地，不能單獨當完整名單。
- [台鐵官方研究資料之各運務段受檢車站表](https://tip.railway.gov.tw/tra-tip-web/tip/file/fc933260-0ef9-4336-8081-8086874ec0ef)：交叉補核臺中、新竹、嘉義、臺南、瑞芳的等級。

官方即時車站地圖本次重新導向訂票頁，因此採上述公開資料交叉整理，並非即時分級 API。
